# YT Learning Loader

A self-contained local learning webapp: scrape YouTube channels, let an AI
agent turn videos into structured learnings and interactive lessons, and
build a personal skill library from what you've learned. Python standard
library only — no frameworks, no build step, one folder, runs locally.

## What it does

- **Scrapes YouTube** — add single video URLs or whole channels; downloads
  metadata, thumbnails, and transcripts (yt-dlp + the Innertube API).
- **AI-extracted learnings** — per video: summary, skills, key points with
  timestamps, and a mermaid diagram, generated by a local agent (Kimi Code
  CLI). Skill names are auto-normalized against a canonical taxonomy so the
  library stays distinct as it grows.
- **Teach Me workspaces** — freestyle topics or whole videos. An agent
  interviews you about your goals, confirms a mission, then builds numbered,
  self-contained HTML lessons (with quizzes, exercises, and cheat sheets)
  that open right in the app. Finished workspaces become installable
  `SKILL.md` files.
- **Skill library** — "Known skills" (from learned videos + distilled
  workspace skills) vs "skills to learn", with one-click teach-me jumps;
  skills install into `~/.kimi-code/skills` for use in any agent session.
- **11 tabs** — Overview, Teach Me, Visualization (mermaid diagrams with
  zoom), Relationships (cross-video skill graph), Videos (sortable table +
  scraping jobs), Learned, My Skills, Profile, Tests (in-app test runner),
  Structure (file map with peek-inside previews), Settings.

## Quickstart (Windows)

```bat
start.bat
```

or manually:

```bat
.venv\Scripts\python.exe launch.py    :: runs the test suite, then serves
```

Then open http://127.0.0.1:8471 (the browser opens automatically).
Requires Python 3.15 in `.venv` (already present) and the
[Kimi Code CLI](https://www.kimi.com/code) on PATH for agent features
(teach workspaces, learnings generation, skill distillation).

## Running the tests

```bat
.venv\Scripts\python.exe tests\run.py
```

175 tests: server endpoints, scraper helpers, workspace/agent flows, the
skill taxonomy guard, file-preview API — plus a JS smoke test that renders
every tab of the UI against a stubbed DOM (`node tests/js_smoke.js`).

## Layout

```
server.py            stdlib HTTP server: JSON API + static files + agent jobs
scraper.py           channel/video metadata, transcripts, thumbnails
launch.py            test-then-serve launcher used by start.bat
static/js/           one file per tab + core.js (shared helpers, no framework)
static/styles.css    the whole design system
data/                videos.json index, learnings/, (gitignored: thumbs,
                     transcripts, logs, runtime state)
teach/<id>/          teaching workspaces (MISSION.md, lessons/, agent console
                     state) — gitignored, personal
skills/<slug>/       reusable SKILL.md files created from videos/workspaces
tests/               unittest suite + test runner + JS smoke harness
```

## Data & privacy

Everything is local by design. `data/videos.json` and `data/learnings/` are
tracked in git as a backup of the curated library; thumbnails, transcripts,
server logs, and `teach/` workspaces (they contain your learner profile)
are gitignored and never leave the machine.
